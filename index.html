Shop drawings, drawn into AutoCAD.

Set the member parameters in a panel docked beside AutoCAD. JI-DETAILER details the member, checks it against the code, and writes the finished sheet onto its own layer standard — sections, bar callouts, splice zones, dimensions and the schedules that go with them.

A panel, not an application

The window is 300 px wide on purpose. It docks against the edge of your screen and stays on top, so AutoCAD keeps the room it needs.

  • An icon rail picks the member. Everything else in the window is the parameter form for it.
  • The drawing is its own OS window. Drag it to a second monitor and leave it open while you work.
  • The code verdict sits in the footer. Click it for the full finding list, clause by clause.
  • Nothing reaches the drawing until you press Draw. The preview tracks the form as you type.

What it draws

Every member type produces a complete sheet, not a sketch: plans, sections, dimensioned bar callouts, levels, and the notes a fabricator actually needs.

The schedules come with it

Not a second tool, and not a spreadsheet to reconcile. The bending schedule, the hook table and the lap-splice table are generated from the same detail, so they cannot disagree with the drawing beside them.

How it works

JI-DETAILER drives the AutoCAD session already open on your desk. There is no export, no import, and no file passed between them.

  1. ConnectIt attaches to your running AutoCAD over ActiveX and draws into that drawing.
  2. Set the memberPick the type from the rail and fill in the parameters. The drawing window tracks the form as you type.
  3. CheckThe verdict sits in the footer. Click it for every finding, with the clause behind it.
  4. DrawThe finished sheet lands on JI-DETAILER's own layers, ready to plot or fold into your sheet set.

Requirements

  • Windows 10 or 11, 64-bit
  • AutoCAD 2018 or later. JI-DETAILER drives it over ActiveX, and must run at the same privilege level as AutoCAD.
  • Microsoft Edge WebView2 Runtime. The setup checks for it and links to it if it is missing.

Every release carries a SHA256SUMS file. To confirm the installer you downloaded is the one that was published: 

Get-FileHash .\JI-DETAILER-Setup-1.1.0.exe -Algorithm SHA256

Licensing

Offline, single-PC licences. A licence is a small signed file bound to one PC identifier — there is no licence server, and the app never phones home.

  1. Install and launchAn unlicensed copy opens on an activation screen showing that PC's ID, and nothing else.
  2. Send the PC IDPress Copy on that screen and send it to your supplier.
  3. ActivatePaste the licence you get back into the same screen. The app starts immediately — there is no restart.
  4. Keep the certificateA PDF certificate comes with the licence, recording the term, the licence ID and the registered PC.

Upgrading is the same installer over the top. Your licence lives under %LOCALAPPDATA%\JI-DETAILER and is deliberately left alone, so an upgrade never asks you to re-license the same PC. If a PC ID changes — a replaced motherboard or disk, or a Windows reinstall — ask for a replacement licence against the new ID.
