What it draws

Every member type produces a complete sheet, not a sketch: plans, sections, dimensioned bar callouts, levels, and the notes a fabricator actually needs. Everything below is real JI-DETAILER output.

The schedules come with it

Not a second tool, and not a spreadsheet to reconcile. The bending schedule, the hook table and the lap-splice table are generated from the same detail, so they cannot disagree with the drawing beside them.

How it works

The panel is 300 px wide on purpose: it docks against the edge of your screen and stays on top, so AutoCAD keeps the room it needs. The drawing opens as its own OS window — park it on a second monitor and leave it there. JI-DETAILER drives the AutoCAD session already open on your desk, so there is no export, no import, and no file passed between them.

  1. ConnectIt attaches to your running AutoCAD over ActiveX and draws into that drawing.
  2. Set the memberPick the type from the rail and fill in the parameters. The drawing window tracks the form as you type.
  3. CheckThe verdict sits in the footer. Click it for every finding, with the clause behind it.
  4. DrawThe finished sheet lands on JI-DETAILER's own layers, ready to plot or fold into your sheet set.

Requirements

  • Windows 10 or 11, 64-bit
  • AutoCAD 2018 or later. JI-DETAILER drives it over ActiveX, and must run at the same privilege level as AutoCAD.
  • Microsoft Edge WebView2 Runtime. The setup checks for it and links to it if it is missing.

Every release carries a SHA256SUMS file. To confirm the installer you downloaded is the one that was published: 

Get-FileHash .\JI-DETAILER-Setup-1.1.0.exe -Algorithm SHA256

Licensing

Offline, single-PC licences. A licence is a small signed file bound to one PC identifier — there is no licence server, and the app never phones home.

  • Install and launch. An unlicensed copy opens on an activation screen showing that PC's ID, and nothing else.
  • Send the PC ID to your supplier, and paste the licence you get back into the same screen. The app starts immediately — there is no restart.
  • A PDF certificate comes with it, recording the term, the licence ID and the registered PC.

Upgrading is the same installer over the top. Your licence lives under %LOCALAPPDATA%\JI-DETAILER and is left alone, so an upgrade never asks you to re-license the same PC.
